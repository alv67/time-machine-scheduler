Versione 0.1.0 · macOS 14+ · Apple Silicon

Pensata per chi vuole decidere quando parte Time Machine

Time Machine parte in base all'ultimo backup completato. Time Machine Scheduler aggiunge una pianificazione vera: ora, minuti e giorni della settimana.

Orario e giorni

Scegli l'ora esatta e i giorni della settimana. Il backup parte quando decidi tu.

La tua destinazione

Legge la destinazione configurata in Time Machine, locale o di rete, e verifica che sia raggiungibile.

Backup senza sorprese

Salta se il Mac è a batteria, impedisce il sonno durante il backup e avvisa a fine operazione.

Stato e log

Fase, percentuale, ultimo backup e log leggibile con rotazione automatica.

Backup ora

Avvia subito un backup fuori pianificazione, senza aspettare l'orario previsto.

Ripristino pulito

Rimuove daemon, script e log e riporta Time Machine alla frequenza scelta.

Installazione

  1. Scarica il DMG e aprilo.
  2. Trascina TimeMachineScheduler.app nella cartella Applications.
  3. Apri l'app e premi Salva pianificazione: installa il daemon e richiede la password di amministratore.
App non notarizzata. Se macOS blocca il primo avvio, usa Impostazioni di Sistema → Privacy e Sicurezza → Apri comunque oppure esegui: 
xattr -dr com.apple.quarantine /Applications/TimeMachineScheduler.app

Requisiti e limiti

Serve

  • macOS 14 o successivo
  • Mac con Apple Silicon
  • Una destinazione Time Machine configurata
  • Password di amministratore per installare il daemon

Limiti noti

  • Un Mac spento non può essere acceso dalla pianificazione
  • caffeinate non impedisce il sonno con il coperchio chiuso
  • La release attuale non è firmata né notarizzata

Codice e sviluppo

Il progetto è open source su GitHub. Si compila con Swift e i Command Line Tools, senza progetto Xcode: 

make test
make app
make install
